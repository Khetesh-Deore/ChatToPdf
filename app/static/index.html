How it works

  1. Fetch. The server opens the share page in a real browser (Chromium via Playwright), waits for all content to render, then extracts each message.
  2. Process. Math formulas are recovered from KaTeX annotations and re-rendered. Code blocks are syntax-highlighted. Images are downloaded, resized and embedded.
  3. Print. The processed conversation is laid out in a clean chat template and exported to A4 PDF with page numbers.

Known limitations

  • The link must be set to public in ChatGPT.
  • ChatGPT may serve a bot-check page. If that happens, use the Saved HTML file tab instead.
  • OpenAI can change the page markup at any time. If a live fetch produces an empty PDF, the saved-file route is a reliable fallback.
  • Generated PDFs are deleted from the server after 30 minutes. Download immediately after conversion.
